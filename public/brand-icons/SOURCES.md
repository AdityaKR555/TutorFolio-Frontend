- facebook: [facebook.svg](https://raw.githubusercontent.com/simple-icons/simple-icons/32e030086fdc605196391aab28519b14dc4295b4/icons/facebook.svg)

- whatsapp: [whatsapp.svg](https://raw.githubusercontent.com/simple-icons/simple-icons/32e030086fdc605196391aab28519b14dc4295b4/icons/whatsapp.svg)
- telegram: [telegram.svg](https://raw.githubusercontent.com/simple-icons/simple-icons/32e030086fdc605196391aab28519b14dc4295b4/icons/telegram.svg)
- linkedin: [linkedin.svg](https://raw.githubusercontent.com/simple-icons/simple-icons/11.15.0/icons/linkedin.svg)
- youtube: [youtube.svg](https://raw.githubusercontent.com/simple-icons/simple-icons/32e030086fdc605196391aab28519b14dc4295b4/icons/youtube.svg)
- x: [x.svg](https://raw.githubusercontent.com/simple-icons/simple-icons/32e030086fdc605196391aab28519b14dc4295b4/icons/x.svg)

Shapes are stored locally in `src/components/socialBrandPaths.js`; no runtime CDN requests are made. Colors and button styling belong to the consuming platform or theme. The legacy `twitter` key uses the current X logo.
